# 🚀 Spring Mastery Hub - UTS Pemrograman Berbasis Framework

Repositori ini berisi penyelesaian tugas Ujian Tengah Semester (UTS) Mandiri menggunakan **Spring Boot (Java & Maven)** dengan antarmuka web minimalis tanpa JavaScript.

---

## 📋 Daftar Isi & Penjelasan Soal

### 1. Soal 1: Analisis 5W Spring Framework
* **File Terkait:** `soal-1-penjelasan-spring.txt`
* **Ringkasan Analisis:**
  * **What:** Framework berbasis Java untuk pengembangan aplikasi backend & web.
  * **Who:** Diciptakan oleh Rod Johnson, kini dikelola oleh VMware.
  * **When:** Digunakan saat membangun REST API atau sistem aplikasi skala menengah hingga besar.
  * **Where:** Diterapkan di lingkungan server/backend.
  * **Why:** Mempermudah struktur kode dan mendukung fitur *Dependency Injection*.

### 2. Soal 2: Program John Travolta
* **Endpoint URL:** `/john-travolta`
* **Penjelasan:** Menampilkan halaman web minimalis berupa kartu informasi topik John Travolta dengan tombol navigasi kembali ke beranda.

### 3. Soal 3: Kalkulator Persamaan Kuadrat
* **Endpoint URL:** `/kuadrat`
* **Penjelasan:** Menyediakan antarmuka *form* HTML interaktif tanpa JavaScript untuk menghitung Diskriminan ($D$) dan akar-akar persamaan kuadrat secara otomatis di backend Java.
